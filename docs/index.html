catch22 - a reasoning effort lab

catch22.aikitchen.cc github

Helping people understand how to select reasoning types and effort levels. Turbo Brilliance adds twelve distinct reasoning modes; this lab measures what each one costs. Static project page; the live lab matrix is at /results.html.

Status: the lab is measured. 11 runs, 1,296 cells, 1.68M generated tokens, every control variant answered.

Turbo-Brilliance - AI Constructs, 50x Reasoning / Instruct. Artwork and model design by DavidAU (David Belton).

The reasoning types

Twelve distinct reasoning modes, each one a plain text tag sent with your prompt. They are ordered by measured effort: average completion tokens per row across our 21 prompt set.

Plus {REASON:off} to return to stock behavior and {REASON:help} to ask the model for its own menu.

The instruct family is the same 12 modes with an i prefix, for example {REASON:ilow}. On the 8B tune we measured instruct inert: token counts within noise of reasoning. The 2.6B sibling is real but partial. On this model, pick from the list above.

Named after Catch-22

https://en.wikipedia.org/wiki/Catch-22

A Catch-22 is a paradoxical, no-win situation from which an individual cannot escape because of mutually contradictory rules, conditions, or circular logic.

The classic military rule: You can be excused from dangerous combat missions only if you are insane, but asking to be excused proves you are rational and sane enough to fly.
