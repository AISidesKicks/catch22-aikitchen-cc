Pick your reasoning mode

Everything below is measured in our own lab: one model, one GPU, same prompts, fresh chat per cell. Live tables: results.html. Method and numbers: mds/benchmarks.md.

Honest framing first. These modes are prompt behavior priming that DavidAU fine tuned into the model. Not search algorithms, not routers. Tree-of-thought output in deeptree is the model role playing the method, not real branching search. The differences you buy are output structure, effort and length. That is still a useful dial - but it is a dial on behavior, not an oracle.

The system in one paragraph

You send a mode tag as plain text with your prompt, for example {REASON:logic} your question. The model has been fine tuned to recognize these tags and change how it answers. No app changes, no API switches, any chat UI or HTTP call works. Two families exist: reasoning modes ({REASON:omni}) and instruct modes ({REASON:iomni}), plus {REASON:off} to return to stock behavior and {REASON:help} to ask the model itself for the menu.

Two findings you will not get from the model card

  • The low tag throttles style, not budget. On easy tasks low mode is the cheapest cell by far (95 tokens for a GCD where high used 636). On a hard paradox, low mode rambled to our 4096 token cap just like ultra did. The tag tunes how it thinks, not whether it stops.
  • Structural modes have effectively unbounded chains. On open ended tasks, deeptree, spoon and omni hit every cap we set (2048, 3072, 4096) without finishing. Plan for a token budget when you use them.

The card rule "quant level gates mode power" shows up in our data as chain control: the lower quant rambles and truncates in structural modes, the higher quant finishes.

Instruct modes: what the tags really do

  • 8B X12 model: live verified - the instruct family is not a separate mode set on this tune. The model's own help menu lists no instruct modes and A/B runs show token counts within noise of the reasoning run. Send {REASON:ilow} if you like, but expect reasoning-grade output.
  • 2.6B X12 sibling: instruct is real but partial. The quick tiers are genuinely leaner (medium 561 vs 1286 tokens on the 8B), yet structural modes ramble harder at small scale.
